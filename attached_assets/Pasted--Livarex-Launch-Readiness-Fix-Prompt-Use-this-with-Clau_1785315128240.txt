I'm launching livarex.com.ng at end of this month and need to fix critical trust/data-integrity issues before it goes live. Work through these in priority order:

## 1. Fix inconsistent/fake stats (HIGHEST PRIORITY)
The site currently shows different, hardcoded property/landlord counts on different pages that contradict each other and don't match reality:
- Homepage top section: "12+ Verified Properties / 12+ Verified Landlords / 12+ Requests Processed"
- Same homepage, lower section: "307+ Verified Properties / 108+ Verified Landlords / 80+ Requests Processed"
- About page: "2,400+ Active Listings / 850+ Verified Landlords / 36 Cities Covered"
- Actual `/listings` page query returns 0 properties

Fix: Replace all hardcoded stat blocks with a single shared component that pulls live counts from the database (actual listing count, actual approved-landlord count, actual submitted-request count). If live counts are currently near-zero, do NOT fake them — instead:
- Either hide the stats section entirely until there's real inventory to show, or
- Reframe the copy to early-access language (e.g., "Now onboarding landlords across Lagos & Ogun" instead of a specific inflated number)

Find every instance of these hardcoded numbers across all pages/components and consolidate into one source of truth.

## 2. Resolve empty listings state
`/listings` returns "0 properties found" while the rest of the site markets an established marketplace. Before launch:
- Seed a real, verified batch of listings (minimum viable number — confirm target with the team) so the core browse flow isn't empty on day one, OR
- If inventory won't be ready by launch, add a proper empty state (e.g., "New listings added daily — request a property and we'll notify you" with a working request form) rather than a bare "0 properties found"

## 3. Audit testimonials for authenticity
The three testimonials on the homepage (Adebayo O., Chidinma E., Emeka N.) need a verifiable source before launch — either real user consent/quotes on file, or remove them. Fabricated testimonials are a legal exposure risk (false advertising) in addition to a trust issue. Flag which ones (if any) are real and replace/remove the rest.

## 4. Fix or remove `/blog`
The blog route currently falls back to rendering the homepage instead of a real blog page. Either:
- Build a minimal working blog listing page (even with 1-2 seed posts), or
- Remove the "Blog" link from the footer until it's ready

## 5. Clean up duplicate/redundant homepage sections
The homepage has two stats blocks with conflicting numbers (see #1) — consolidate into one section in the final layout, don't just fix the numbers.

## 6. QA pass on "Soon" features
Confirm "Buy" and "Commercial" nav items (marked "Soon") don't lead to broken/empty routes if clicked — they should either be non-clickable/disabled or route to a proper "coming soon" page.

## 7. Sanity-check city coverage claims
About page claims "36 Cities Covered" but only Lagos and Ogun have live city pages (`/properties-in/lagos`, `/properties-in/ogun`). Update this number to match actual coverage, or remove it until more cities are live.
